# 示例数据说明

这个目录包含项目的示例数据，用于：

1. **GitHub展示** - 小量数据可以直接上传到GitHub
2. **功能测试** - 快速验证系统功能
3. **格式参考** - 展示正确的数据格式

## 文件结构
```
sample_data/
├── images/          # 示例图片（建议不超过10张）
└── labels/          # 对应标签文件（YOLO格式）
```

## 类别说明
- 类别0: Ship (船舶)
- 类别1: Container (集装箱)  
- 类别2: Crane (起重机)

## 使用建议
- 保持图片数量在10张以内，确保GitHub上传顺畅
- 图片和标签文件需要一一对应
- 使用标准的YOLO格式标签
